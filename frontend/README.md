# ArtHub Frontend

This frontend now uses Vue 3, Vue Router, TypeScript, and Vite.

## Setup

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Default dev host: `http://localhost:3000`

The frontend uses `VITE_API_BASE_URL` and falls back to `http://localhost:8080`.

## Scripts

- `npm run dev`
- `npm run build`
- `npm run preview`
